## Method

`runtime/emul/league_watched_complete.py` starts from the T100 preparation state
(`3abfd6b0…`) and records 64-tick chunks of ordered RNG, tick/ball/score state and
every accepted `0AB9:0F94/0FFC` action to the first `0AB9:E1F2` return. Two
interventions are recorded and checked:

1. **Watch flag.** `config+F2` is set from 0 to 1 on the loaded T100 state. The
   unforced league quick path ends before the friendly observer's `0AB9:E24C` site
   (attempt 2: 0 watched ticks, 20,734 draws), so the flag must be set earlier.
2. **Match timer.** The T100 quick-path state carries the unprogrammed PIT divisor
   `65536`; the watched friendly's match setup programs `1024`. At 65536 the watched
   league spends ~3.5 minutes per tick (4 ticks in 13 minutes). The observer restores
   `1024` at the first watched tick (30 ticks in ~95 s, matching the friendly's
   watched rate).

The first watched tick is required to be `quick=0`, seed `18521`, score `0-0`,
elapsed `0`, remaining `91`.
