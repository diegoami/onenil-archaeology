## Why this capture exists

T123 is the **quick (Watch-off)** path: 7 dispatcher actions, 2-0, 20,734 draws,
exactly T117/T102 (T123 commit `000fe17`). The native watched league session emits
839 events and a 2-1 result, so before T124 there was **no original watched league
reference**. The documented "2-1 against 2-0" compared a watched run with a quick
run; it was a path difference, not a demonstrated watched-engine divergence.

## Method

`runtime/emul/league_watched_complete.py` starts from the T100 preparation state
(`3abfd6b0…`) and records 64-tick chunks of ordered RNG, tick/ball/state and every
accepted `0AB9:0F94/0FFC` action to the first `0AB9:E1F2` return. Two interventions
are recorded and checked:

1. **Watch flag.** `config+F2` is set from 0 to 1 on the loaded T100 state. The
   unforced league quick path ends before the friendly observer's `0AB9:E24C` site
   (attempt 2: 0 watched ticks, 20,734 draws), so the flag must be set earlier.
2. **Match timer.** The T100 quick-path state carries the unprogrammed PIT divisor
   `65536`; the watched friendly's match setup programs `1024`. At 65536 the watched
   league spends ~3.5 minutes per tick (4 ticks in 13 minutes). The observer restores
   `1024` at the first watched tick (30 ticks in ~95 s, matching the friendly's
   watched rate).

The first watched tick is required to be `quick=0`, seed `18521`, elapsed `0`,
remaining `91`. The recorded `scores` field is the legacy D086/D087 scratch pair,
**not** the live D0C4/D0C5 score; it stays 0-0. The live score is taken from the
accepted code-38 goal actions for this capture.

## Native alignment (prefix evidence)

original stream agrees with the native watched session on **every action** — code,
player, secondary, side, club, minute and tick — including the **56' goal** by player

The D086/D087 scratch score pair remains 0-0 in both the capture and the native
session's own tick state until the live bytes are read; the native's `tick_live_goals`
(D0C4/C5) is the live score, and the action stream is the reliable cross-check. The
goal actions through minute 59 are identical.
