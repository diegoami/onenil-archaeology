# T07 The match's structure: from 0AB9:E1F2 to every routine that draws

- **Kind**: research (static, with traces)
- **Issue**: #39 · **Branch**: `task/T07-match-structure` · **Merge after**: T06
- **Evidence**: F02 (the match's entry `0AB9:E1F2`, its seed `0AB9:19CA`, the generator `24BC:0CDC` and
  its wrappers), F06 and `traces/T06/cf7eb2d04211ba88-week-r0003.jsonl` (23,006 draws, each with up to 4
  return addresses; the managed match is draws 0–5,852). Claims are `[confirmed]` from the listing
  and the decompile (`static/1-0-exe/`) and from traces; finding `F07`.
- **Owns**: `tools/static/drawsites.py`, `tests/static/test_drawsites.py`, `static/1-0-exe/drawsites.tsv`,
  `static/1-0-exe/match-structure.md`, `findings/F07-*`.
- **Scope**: the claim: *every draw of the managed match comes from a routine of the listing whose
  place in the match's call tree, argument n and use of the result are stated*.
  - `tools/static/drawsites.py` reads a trace and the listing and writes `static/1-0-exe/drawsites.tsv`:
    one row per draw site (the game routine that asks, the instruction after its call), with its n
    values, its count in the managed match and in the rest of the week, and its routine's area
    (`static/1-0-exe/index.tsv`).
  - `static/1-0-exe/match-structure.md`, written from the listing and the decompile: the call tree
    from `0AB9:E1F2` down to the draw sites; the match's loop (what one iteration is: a tick, an
    event), how it ends (full time, the result stored where); for each draw site, what its result
    decides (compared with what, which branch, which variable), as far as the code shows.
  - **Out of scope**: modelling a rule; the watched match's pitch display; the weekly work after the
    match return.
- **Milestones**: (1) the draw-site table; (2) the call tree and the loop; (3) each site's use; (4) F07.
- **Done when**:
  1. `python3 tools/static/drawsites.py traces/T06/cf7eb2d04211ba88-week-r0003.jsonl static/1-0-exe/drawsites.tsv`
     rewrites the committed file byte for byte, and every draw of the managed match (draws 0–5,852)
     falls in exactly one row.
  2. `python3 -m pytest tests/static/test_drawsites.py` passes (synthetic traces).
  3. `static/1-0-exe/match-structure.md` names, for every row of the managed match's draw sites, the
     routine, its caller chain up to `0AB9:E1F2`, and what the result decides, each with a listing
     address; a site whose use is not read says so.
  4. `findings/F07-match-structure.md` exists, status `proposed`.
  5. `python3 tools/check_originals.py` exits 0.
- **Hazards**: a caller chain from the BP frames can skip a routine without a frame; check each chain
  against the listing's calls. The decompile is evidence to check (rule 11): signedness, segments.
