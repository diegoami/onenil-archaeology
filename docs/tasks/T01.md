# T01 Inventory: both editions hashed, compiler and run-time identified, 95 vs 96

- **Kind**: research (static)
- **Issue**: #2 · **Branch**: `task/T01-inventory` · **Merge after**: none
- **Evidence**: none yet. The task's claims are `[confirmed]` from static bytes, each citing the
  file's sha256 and an offset; the editions' relation is `[derived]` from them. Finding `F01`.
- **Owns**: `tools/inventory.py`, `tools/static/unlzexe.py`, `tests/**`, `records/T01/**`,
  `findings/F01-inventory.md`, `.github/workflows/ci.yml`.
- **Scope**: the one claim: *what the two editions are, byte for byte*.
  - **Inventory**: every file of `One-Nil95/` and `One-Nil96/` (from `.cache/`): name, size,
    sha256, DOS timestamp, type (MZ, packer, data). A JSON record per edition, plus the unpacked
    sizes and sha256 of every LZEXE executable.
  - **Unpack**: `tools/static/unlzexe.py`, ported from goal2-archaeology (`tools/static/unlzexe.py`
    at the cited commit), with a test against a synthetic LZEXE file that holds no original byte.
  - **Compiler and run-time**: of `1-095.EXE` and `1-0.EXE` (and, briefly, `ALTER.EXE`, `HELP.EXE`,
    `INSTALL.EXE`): compiler, version and run-time library, from signatures (copyright strings, the
    run-time error table, the System unit's entry and exit code, overlay or unit layout), each with
    its offset. Name what is inferred rather than seen.
  - **95 vs 96**: which files are identical, differ, or exist in one edition only. For the differing
    files, the size and the changed byte regions. For the two EXEs (unpacked): the header and segment
    layout, the strings in one and not the other, and the changed regions by segment. This is no
    code-level reading yet (T02).
  - **Out of scope**: disassembly, data-file layouts, running the game.
- **Milestones**: (1) the inventory record pushed; (2) the unpacker and both unpacked hashes; (3) the
  compiler finding; (4) the 95→96 delta and `F01`.
- **Done when**:
  1. `python3 tools/inventory.py --check records/T01/inventory.json` exits 0: every file in `.cache/`
     matches its recorded size and sha256, and none is missing or extra.
  2. `python3 -m pytest tests/test_unlzexe.py` passes, and `python3 tools/static/unlzexe.py`
     reproduces the unpacked sha256 of both main EXEs recorded in `records/T01/inventory.json`.
  3. `findings/F01-inventory.md` exists with status `proposed` and names the compiler, its version
     and the run-time of both main EXEs, each with an offset.
  4. `records/T01/diff-95-96.json` lists every file of both editions as `same`, `differs`, `95 only`
     or `96 only`.
  5. `python3 tools/check_originals.py` exits 0, and no record holds more than 64 consecutive bytes of
     an original file (`tools/inventory.py --check-embed`).
- **Hazards**: committing a string table or a hexdump of the original (rule 14): records hold
  digests, offsets, counts and short identifying strings only. And trusting a copyright string as the
  compiler's version: confirm it from the run-time's code.
