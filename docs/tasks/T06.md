# T06 The Unicorn harness: run 96's match from a recorded state and trace its draws

- **Kind**: runtime (harness)
- **Issue**: #11 · **Branch**: `task/T06-harness` · **Merge after**: T04
- **Evidence**: F02 (the match entry 0AB9:E1F2, its seed 0AB9:19CA, the LCG 24BC:0CDC on RandSeed
  DS:A51C), F04 (savestates of 96 before a match; the same week replays the same menus), CLAUDE.md
  rule 15 and docs/plan.md (traces, no Python model). goal2-archaeology's harness
  (`runtime/emul/watched_match.py`, its `Guest` resumed from a savestate's CPU state, at 774473eb).
  Finding `F06`.
- **Owns**: `runtime/emul/**`, `tests/emul/**`, `runs/T06/**`, `traces/T06/**`, `findings/F06-*`.
- **Scope**: the claim: *a match of 96 runs as guest code under Unicorn from a recorded state, and
  its draws are traced*.
  - Port goal2's `Guest`: memory and CPU state from a DOSBox-X 2024.03.01 savestate (calibrate the
    CPU component's layout for 96's states), DOS and BIOS calls the match makes stubbed or served
    and listed, a hook that replaces a routine.
  - Run one match (a friendly of SAVE1, F04's week 1) from a savestate taken at its pre-match
    screen, to its result, with Watch match off; trace every call of `24BC:0CDC` (seed before and
    after, n, the caller) and the match's result as the game stores it.
  - The trace format, as onenil's Rust tests will read it: one JSON lines file per match under
    `traces/T06/`, documented in `runtime/emul/README.md` (fields, units, how to replay).
  - Compare with the original: the same match run in DOSBox-X (F04's records) gives the same
    result screen.
  - **Out of scope**: reading the engine's rules; the watched match's pitch.
- **Milestones**: (1) the guest resumes from a savestate and runs to a known address; (2) one
  match to its result; (3) the trace and its format; (4) F06.
- **Done when**:
  1. `python3 -m pytest tests/emul` passes (unit tests on synthetic states, no original byte).
  2. `python3 runtime/emul/match.py --state <sha256> --out traces/T06/` writes a trace whose final
     score equals the score on the result screen of the same week in DOSBox-X (a T04 record cited).
  3. Running it twice gives byte-identical traces.
  4. `findings/F06-harness.md` exists, status `proposed`; `runtime/emul/README.md` defines the trace.
  5. `python3 tools/check_originals.py` exits 0; traces hold draws and results, no game bytes.
- **Hazards**: a savestate's CPU state is mid-interrupt or mid-key-wait; resume where the match
  starts, not anywhere. goal2's offsets are GOAL's: every address comes from F02 and the listing.
