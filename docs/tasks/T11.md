- **Evidence**: F02's RNG, F07's `0AB9:D983`, F09's ratings, F08's six distinct weeks and 15

- **Owns**: `runtime/emul/contests.py`, `tests/emul/test_contests.py`, `runs/T11/**`,

- **Scope**: establish a callable original-routine contract for onenil's first Rust slice.

  Export immutable JSONL input/output cases with each expected draw and provenance; a derived
  index maps all 15 T08 traces to the six routine runs. No game bytes, Python engine model,
  ratings implementation, whole-match/week parity or watched-engine claim is in scope.
- **Milestones**: (1) static contract, recorder and synthetic checks committed/pushed;
  (2) six original runs and decoded fixtures committed/pushed; (3) corpus verification and F11.
- **Done when**:
  1. `python3 runtime/emul/contests.py --check` exits 0: six completed routine runs, 558 calls,
     exact recorded input/output and draw-span linkage, and all 15 T08 traces accounted for.
  2. `python3 -m pytest tests/emul/test_contests.py` passes, including corrupted or missing spans,
     wrong state/seed and an incomplete run rejected; the checker does not implement D983.
  3. `python3 runtime/validate.py runs/T11` and `python3 -m pytest tests` pass.
  4. `static/1-0-exe/quick-contests.md` and proposed `findings/F11-quick-contests.md` state the
     contract, addresses, measured coverage and limits; fixture provenance includes code commits

  Routine parity is not the quick match's clock/minute-fill loop or whole-week replay parity.
