# T08 A trace corpus: T04's weeks traced in the harness, each checked against DOSBox-X

- **Kind**: runtime (harness)
- **Issue**: #40 · **Branch**: `task/T08-trace-corpus` · **Merge after**: T06
- **Evidence**: F04 (the week records `T04-week-r0001`…`r0018` and their kept savestates: each week's
  start state is the previous record's end savestate), F06 (the harness; one week traced and
  compared). Finding `F08`.
- **Owns**: `runtime/emul/corpus.py`, `tests/emul/test_corpus.py`, `traces/T08/**`, `runs/T08/**`,
  `findings/F08-*`.
- **Scope**: the claim: *the harness reproduces every completed T04 week from the same start state,
  screen for screen, and each such week's trace is in the corpus*.
  - `runtime/emul/corpus.py`: for each completed T04 week record, find its start state (the
    `start_state.sha256` it names), run `match.py`'s week with `--compare` against that record, and
    collect a corpus index `traces/T08/index.json`: per week the record, the trace, its sha256, the
    comparison verdict, the result, the draws.
  - Weeks the harness's screen rules do not cover yet (a contract, a sale, a league match's
    ineligible-player stop) are listed with why, not forced.
  - **Out of scope**: the watched match (Watch match was off in every T04 week); new DOSBox-X runs.
- **Milestones**: (1) the corpus tool; (2) the runs, pushed as they come; (3) the index and F08.
- **Done when**:
  1. `traces/T08/index.json` lists every completed T04 week record (15), each with a trace and a
     comparison verdict.
  2. Every listed week whose screens the harness covers has the verdict "all screens met in order";
     the others name the screen that stopped them.
  3. `python3 runtime/validate.py runs/T08` exits 0 and `python3 -m pytest tests/emul` passes.
  4. `findings/F08-trace-corpus.md` exists, status `proposed`.
  5. `python3 tools/check_originals.py` exits 0.
- **Hazards**: a T04 week whose start was a session continued, not restored, starts from the previous
  record's last savestate: check that the sha256 the record names is the file used.
