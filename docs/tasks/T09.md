# T09 The match's ratings: where D983's four values come from

- **Kind**: research (static, with traces)
- **Issue**: #43 · **Branch**: `task/T09-ratings` · **Merge after**: T07
- **Evidence**: F07 (`0AB9:D983` contests `DS:D674`, `D678`, `D67C`, `D680`, two words each, one per
  side; `1B55:50EB` is called for both sides before each `D983`), F03 and F05 (the player records
  `[DS:D7BA]` 8 bytes, `[DS:D7BE]` 15 bytes, the club records `[DS:D7C2]` 62 bytes, … in memory),
  F08's corpus (six distinct matches). Claims are `[confirmed]` from the listing and from values
  read in the harness; finding `F09`.
- **Owns**: `tools/static/ratings.py`, `tests/static/test_ratings.py`, `static/1-0-exe/ratings.md`,
  `runs/T09/**`, `findings/F09-*`.
- **Scope**: the claim: *each of D983's four values, for each side, is computed from stated fields of
  stated records by a stated formula, and the formula gives the values the original computed*.
  - Read `1B55:50EB` and what it calls, in the listing: which records and fields (by record, offset
    and size) feed `DS:D674`–`D680`, and how (sums, weights, divisions, caps). Name the four by what
    the code does; whether they are the screen's goalkeeper, defence, midfield and attack follows
    from the code or a run, not from their order.
  - `tools/static/ratings.py`: a run in the harness from each distinct start state of F08's corpus,
    stopped at each `D983` entry of the managed match, reading the four arrays and the fields the
    reading names (a run record per state, values not bytes: the ratings are numbers the game
    computes, the fields are decoded values); and a check that the formula as read reproduces every
    value read.
  - **Out of scope**: the watched match (T10); player development over a season.
- **Milestones**: (1) the reading; (2) the harness reads; (3) the check and F09.
- **Done when**:
  1. `static/1-0-exe/ratings.md` states the formula of each of the four values with listing addresses.
  2. `python3 tools/static/ratings.py --check runs/T09` exits 0: for every `D983` entry recorded in
     `runs/T09` (all six distinct weeks of F08), the formula reproduces all eight values.
  3. `python3 -m pytest tests/static/test_ratings.py` passes; `python3 runtime/validate.py runs/T09` exits 0.
  4. `findings/F09-ratings.md` exists, status `proposed`.
  5. `python3 tools/check_originals.py` exits 0.
- **Hazards**: signed and unsigned arithmetic, byte vs word fields, integer division order (rule 11):
  the check against the read values is what decides, not the decompile.
