# T03 Data layouts: the league files, the font, the palette, the save

- **Kind**: research (static)
- **Issue**: #4 · **Branch**: `task/T03-data-layouts` · **Merge after**: T01
- **Evidence**: F01 (the files and their hashes). Claims are representation claims `R<nn>`,
  `[confirmed]` from bytes (sha256 + offset) and, where T02 has it, the code that reads them; F03.
- **Owns**: `tools/data/**`, `tests/data/**`, `records/T03/**`, `findings/F03-*`.
- **Scope**: the claim: *the structure of every data file, proposed from its bytes*.
  - `ENGL-94.DAT`, `ENGL-95.DAT`, `SCOT-94.DAT`, `ITAL-94.DAT`: header, record size, counts (clubs,
    players, divisions), string encoding, the fields of a club and of a player. Decoders that print
    decoded values (names, ratings) into records, never raw bytes.
  - `1-0.TFN` (and its 95→96 change) and `1-0.PAL`: format only.
  - `SAVE1.1-0` (194,426 bytes in both editions, different bytes): its sections, as far as bytes and
    the league files show them.
  - **Out of scope**: what a field does in play (later tasks); running the game.
- **Milestones**: (1) the league-file layout and decoder; (2) font and palette; (3) the save; (4) F03.
- **Done when**:
  1. `python3 tools/data/league.py --check .cache` decodes all four league files with no byte left
     unexplained or marked `unknown`, and its counts match `records/T03/leagues.json`.
  2. `python3 -m pytest tests/data` passes on synthetic fixtures holding no original byte.
  3. `findings/F03-data-layouts.md` exists, status `proposed`, one `R<nn>` per field.
  4. `python3 tools/check_originals.py` exits 0.
- **Hazards**: guessing a field's meaning from its range: name it by position until code or a run says
  what it is.
