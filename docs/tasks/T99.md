# T99 Never track the private cache; restore what needs no credentials

- **Kind**: correction · **Issue**: #221 · **Branch**: `task/T99-private-cache`.
- **Evidence**: [confirmed:incident 2026-11-20] A T98 worktree used
  `.cache -> <primary>/.cache` for a digest-pinned restore. `git add -A`
  staged that symlink because `.gitignore`'s `.cache/` matches a directory, not
  a symlink; it merged in a06d3f3 (PR #220) and the next `git switch main`
  replaced the primary's real 41 GB `.cache` directory with the tracked link.
  Ignored artifacts were deleted; no committed record was.
- **Owns**: `.gitignore`, `tools/check_originals.py`, its tests, `CLAUDE.md`,
  `docs/artifacts.md`, and the removal of the tracked `.cache` entry.
- **Scope**: [designed] make the repository refuse this class of mistake. Remove
  the tracked `.cache` path; ignore the name both as a directory and as a file
  or symlink; extend the original-byte check (which CI already runs) to fail on
  any tracked `.cache` path; record the lesson where every client reads it. Do
  not attempt to reconstruct private savestates, do not add a bypass flag for
  artifacts, and do not vendor or download game bytes. Restoring the pulled
  originals needs the owner's rclone login and stays out of this task.
- **Milestones**: incident issue; frozen task; guard plus lesson; checks and CI;
  merge with a merge commit; a checkpoint naming what remains unrecoverable.
- **Done when**:
  1. `git ls-files | grep -c '^\.cache'` prints 0 and `python3 tools/check_originals.py`
     reports `original-file check: ok`.
  2. A staged `.cache` symlink makes `python3 tools/check_originals.py` fail with
     `private cache path tracked: .cache`, shown before and after the fix.
  3. `git check-ignore -v .cache` matches the ignore rule for a symlink of that
     name, and CI passes.
- **Hazards**: `git add -A` and `git add .` stage ignored-but-unmatched names
  such as this symlink; name every path explicitly in this repository. Never
  "fix" the check by allowing a cache path through.
